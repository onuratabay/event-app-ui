# Uygulama metin incelemesi

25 Ekim 2026. Kaynak kod üzerinden 24 ekran, misafir daveti giriş sayfası, 404 ekranı ve ilgili ortak alanlar incelendi. Bu çalışma gerçek cihazda görsel yerleşim testi değildir. Marka biçimleri ve “Meet real moments.” sloganı korundu; hukuki belge içerikleri değiştirilmedi.

| Ekran | İnceleme sonucu |
| --- | --- |
| AdminScreen | Başvuru kararları, raporlar, kalıcı silme ve yetki mesajları incelendi; işlem sonuçlarını belirten mevcut metinler korundu. |
| AppGuideScreen | Giriş sloganı sadeleştirildi; profil puanı ve referans ipuçları gerçek akışla eşleştirildi. |
| ApprovalScreen | Profil tamamlama çağrısı daha açık yazıldı. |
| AvailabilityScreen | Havuz terimi açıklandı; kaydetme kullanılamazken verilen mesaj ve gün boyu müsaitlik açıklaması düzeltildi. |
| CreateEventScreen | Görünürlük, katılımcı eşiği, seviye, gereksinim örnekleri ve ad/soyad yazımı netleştirildi. |
| DirectChatScreen | İlk mesaj açıklaması ve mesaj alanı noktalaması düzeltildi. |
| DiscoverScreen | Minimum katılımcı sayısının etkinlik yerine sohbet odasını açtığı belirtildi. |
| EventDetailScreen | Oda açılma eşiği, uygun kişi bulunamaması ve tarih/saat başlığı netleştirildi. |
| EventRoomScreen | Yeniden bağlantı ve sessize alma açıklamaları davranışla eşleştirildi; mesaj alanı noktalaması düzeltildi. |
| ForgotPasswordScreen | Kod süresi, yeniden gönderme, parola ve başarı mesajları incelendi; mevcut akışla uyumlu. |
| GuestEventScreen | Misafir erişimi, katılım, kontenjan ve davet hataları incelendi; korundu. |
| InterestsScreen | İlgi alanı ve isteğe bağlı fotoğraf açıklamaları incelendi; korundu. |
| LegalScreen | Yükleme/hata metinleri incelendi; sunucudaki hukuki metinler değiştirilmedi. |
| LoginScreen | Telefonla giriş, şifre kurtarma ve davet metinleri incelendi; mevcut anlam korundu. |
| MapScreen | Konum izni, filtreler, boş sonuç ve yükleme açıklamaları incelendi; korundu. |
| NotificationsScreen | Okuma, silme, bekleyen istek ve boş durum metinleri incelendi; korundu. |
| OnboardingScreen | Instagram bağlantısı izlenimi, gizlilik şakası, e-postayla giriş yönlendirmesi ve süre vaatleri düzeltildi. |
| ProfileScreen | Etkinlik puanı ile kişiye verilen değerlendirmelerin farkı açıklandı; kategori yazımları tutarlı hale getirildi. |
| RateEventScreen | Değerlendirme kategorileri profille aynı yazıma getirildi. |
| RoomsScreen | Boş durum sloganları sadeleştirildi; katılımcı garantisi kaldırıldı; sohbet silmenin karşı tarafa etkisi açıklandı. |
| SearchScreen | Tarih filtreleri, arama ve boş sonuç metinleri incelendi; aramanın teknik kapsamı bu metin çalışmasında değişmedi. |
| SettingsScreen | Mesaj bildirimi açıklamasına bire bir sohbetler eklendi; yazı boyutu ve yönetim açıklamaları sadeleştirildi. |
| SplashScreen | Kısa alt açıklama sadeleştirildi. |
| WelcomeScreen | Slogan korundu; açıklama kısaltıldı ve eyleme dönüştürüldü. |
| Misafir daveti girişi | Davetin yalnızca WhatsApp üzerinden geldiğini varsayan ifade kaldırıldı. |
| 404 | Açıklama ve güvenli geri dönüş seçenekleri incelendi; mevcut metinler korundu. |

Kapsam: Metinler ve ilgili metin beklentileri düzeltildi. Sunucu yetkilendirmesi, sohbet senkronizasyonu ve arama kapsamı gibi önceki kod inceleme bulguları bu çalışmayla giderilmiş sayılmaz.
